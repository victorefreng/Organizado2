# Clips generados con Runway

Deja aquí los MP4 con el nombre del clip tal cual aparece en
`docs/09-prompts-runway.md`:

```
OCEAN-MAIN.mp4
OCEAN-CEILING.mp4
AWK-07-MAIN.mp4
```

Si una tirada te gusta a medias, mándala igual con `-v2` al final. Muchas veces
se salva recortando, cambiando la velocidad o usando solo la primera mitad.

Apunta la semilla de cada una en `SEEDS.txt`: si una funciona y hace falta otra
parecida, con la semilla se repite; sin ella, es empezar de cero.
