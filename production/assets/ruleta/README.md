# Ruleta de RED ROOM

`ruleta.svg` es un gráfico editable con ocho casillas. Van **vacías a propósito**: las opciones las escribe el operador, cambiando el texto de cada `<text id="opcion-N">` (con cualquier editor de texto o con Inkscape).

No forma parte de ningún vídeo. Se muestra aparte, cuando el operador lo decida.
